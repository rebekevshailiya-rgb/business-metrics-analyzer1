# Бизнес-требования к Business Metrics Analyzer

## Цель приложения

Сократить время ручного расчёта финансовых показателей предприятия и предоставить руководителю понятные данные для оценки эффективности работы.

## Пользователи и бизнес-задача

Основные пользователи — руководитель предприятия и бизнес-аналитик. Им необходимо отслеживать выручку за несколько месяцев и оценивать рентабельность продаж, чтобы выявлять периоды снижения доходов и принимать решения о контроле затрат.

## Требования к учебной версии

1. Приложение должно представлять данные о месяцах и выручке в виде таблицы.
2. Приложение должно рассчитывать среднюю выручку за указанный период.
3. Приложение должно рассчитывать рентабельность продаж по формуле: `(выручка − затраты) / выручка × 100 %`.
4. При нулевой выручке функция должна возвращать `0.0` без ошибки деления на ноль. Это условное правило учебной версии: экономически рентабельность при нулевой выручке не определена.
5. Результаты должны выводиться в консоль с понятными русскими подписями. Рентабельность должна отображаться в процентах с двумя знаками после запятой.

## Ограничения и дальнейшее развитие

Учебная версия использует данные, заданные в коде, и запускается на Python 3.10+ с зависимостями из `requirements.txt`. Для начальной версии не требуются база данных и графический интерфейс.

В дальнейшем планируются расчёт прибыли, сравнение показателей подразделений, расчёт изменения выручки относительно предыдущего месяца и построение графиков с помощью matplotlib.

## Критерии приёмки

- Для выручки 120 000, 150 000 и 135 000 среднее значение составляет 135 000.
- Для выручки 150 000 и затрат 120 000 рентабельность составляет 20 %.
- При нулевой выручке функция возвращает `0.0`, программа не завершается с ошибкой деления на ноль.
- После установки зависимостей программа запускается командой `python main.py` и выводит таблицу, среднюю выручку и рентабельность.
