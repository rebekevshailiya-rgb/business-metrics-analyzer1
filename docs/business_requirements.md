# Бизнес-требования

## 1. Назначение

Учебное приложение предназначено для демонстрации базового анализа бизнес-показателей предприятия с использованием Python.

## 2. Бизнес-задача

Необходимо предоставить пользователю возможность получить основные показатели по выручке и рентабельности предприятия на основе исходных данных.

## 3. Основные функции

1. Хранение исходных данных о выручке по месяцам.
2. Расчёт средней выручки.
3. Расчёт рентабельности по формуле:
   Рентабельность = (Выручка - Затраты) / Выручка × 100%.
4. Вывод результатов в консоль.
5. Построение графика динамики выручки.

## 4. Технологические требования

- Python 3.10 или выше;
- pandas;
- matplotlib;
- Git и GitHub для контроля версий.

## 5. Результат

Пользователь получает таблицу исходных данных, среднюю выручку, значение рентабельности и график динамики выручки.
